# Economics Blueprint Explorer

**50 Economics concepts, one Lighthouse Blueprint each. Browse by season, search, dark/light mode.**

Live demo → https://bodhiprotocol.github.io/economics-blueprint-explorer/

---

## Why this exists

Economics is usually taught as abstract theory before intuition. Project Lighthouse reframes each concept as a **Blueprint**: a visual-metaphor card with a core question, one per concept, grouped into seasons that build on each other — from scarcity and trade, through how an economy works, to behavioral economics and the ideas of history's great economic thinkers.

This tool makes all 50 Economics Blueprints browsable and searchable in one place — a companion reference for anyone working through the curriculum.

## What's inside

- All 50 Economics Blueprints, grouped by Season (including a Bonus Season on the thinkers who shaped economics)
- Search across every Blueprint's ID, title, and core question
- Season-filter pills to browse one season at a time
- Click any card to reveal its core question

## Tech

One self-contained `index.html`. No frameworks, no build step, no API calls. Dark/light theme toggle. Data lives in a single in-file JS array sourced from the curriculum docs — no database, manual re-sync only.
